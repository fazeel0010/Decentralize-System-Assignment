# NFT Asset Store Frontend

This project provides the web interface for the NFT Asset Store decentralized application. It is developed with Vue 3 and Vite and connects to an ERC-721 smart contract deployed on the Sepolia test network.

The application allows users to connect their MetaMask wallet, create NFT assets, view available NFTs, list their NFTs for sale, remove them from sale, and purchase NFTs using Sepolia ETH.

## Technologies

The frontend uses the following technologies:

- Vue 3
- Vite
- ethers.js
- MetaMask
- Vue Router
- Axios
- IPFS / Pinata
- Sepolia Testnet

## Install Dependencies

After downloading the project, open the project directory in a terminal and install the required packages:

```sh
npm install
```

## Run the Project

Start the development server:

```sh
npm run dev
```

## Build for Production

Compile and prepare the application for production:

```sh
npm run build
```
